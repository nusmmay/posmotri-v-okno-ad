# Посмотри в окно

Учебный проект Яндекс Практикума: верстка страницы по макету. HTML, скрипт и вспомогательные стили (`preloader.css`, `error.css`) выданы курсом, мной написан файл `styles/style.css`.

Репозиторий: https://github.com/nusmmay/posmotri-v-okno-ad

## Структура

- `index.html` — разметка страницы
- `scripts/script.js` — загрузка и отрисовка данных
- `styles/style.css` — основные стили (БЭМ-классы, flex/grid)
- `styles/preloader.css`, `styles/error.css` — стили прелоадера и экрана ошибки
- `fonts/` — шрифты

## Запуск

Открыть `index.html` в браузере. Для загрузки данных нужен доступ в интернет.
